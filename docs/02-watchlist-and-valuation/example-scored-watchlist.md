# Example scored watchlist

This is a **worked example** of the [beginner selection scorecard](beginner-selection-scorecard.md): the same names a beginner might follow, with **StockFit** and **OptionsFit**. It is not a live brokerage export and not a recommendation to buy, sell, or hold anything.

!!! danger "Not financial advice"
    Scores are an operating draft (listing type, typical options liquidity, business familiarity). They are **not** a live bid/ask check. Confirm chains and fund facts yourself.

Real share counts, account dollars, and personal lots stay in a **private** operator file — not on GitHub Pages.

## Shortlist rule used in the example

| Use | Rule |
|-----|------|
| Own-for-years | StockFit **≥ 2**, then about **5–8** names, not eight copies of one theme |
| Options practice | OptionsFit **≥ 2** |
| Out | Either score **0**, or both scores ≤ 1 |

## Illustrative shortlists (still not advice)

**Own-for-years (example shape):** one all-in-one such as XEQT as **~60%** of that envelope; SHOP up to the **~15%** single-name cap; small slices of AAPL, GOOGL, NDAQ. That is the [core–satellite](beginner-selection-scorecard.md) pattern with percents only.

**Options practice (example):** AAPL, AMZN, GOOGL, NVDA, NFLX, SHOP (U.S. line). Second tier after a live chain check: PLTR, HOOD, NDAQ.

AMZN, NVDA, and NFLX can stay **options-first** so the own-for-years envelope is not a second copy of the U.S. names already inside XEQT.
